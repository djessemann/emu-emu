    games
    nes, snes, game boy, gba and sega files, or .zip. each goes in its system's tab. they're kept in this browser only.
    d-pad
    slide for diagonals.
    a + b
    press between them for both.
    saving
    one save state per game, in the menu. in-game saves are kept too, and games resume where you left off.
    no sound?
    turn off your phone's silent mode.
    controller
    plug in a phone controller and press any button.
    keys
    arrows, z = b, x = a, a = y, s = x, q = l, w = r, enter = start, shift = select, esc = menu. sega: z x c = a b c.
